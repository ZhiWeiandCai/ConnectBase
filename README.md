# ConnectBase

A930RTX快速连接底座(B910S_RTX-BE)的Demo

## 连接操作代码逻辑步骤（详细细节根据代码“及注释”查看）

- 1.通过扫条码方式，获取到底座的SN
- 2.成功获取到底座SN
- 3.搜索周围蓝牙设备(或者蓝牙已经配对，就能够方便直接获取到)，通过SN找到哪一个是底座的蓝牙标识，例如名称
  - 已经配对过的蓝牙设备不需要搜索，直接获取到
- 4.通过蓝牙通道，连接上底座，进行通信
- 5.获取底座WiFi信息SSID、密码，(或者也可以设置WiFi的SSID和密码)
- 6.通过WiFi的SSID、密码，使A930RTX连上底座WIFI。
  - （看项目需求。此处可添加判断逻辑，机器与底座已经连上了，不需要每次都重新连接）
- 7.断开程序的蓝牙连接通道

## 应用操作使用步骤

- 1.底座通电，等待底座系统启动完成。
- 2.打开应用，点击Scan按钮，扫描底座的SN条码。
- 3.等待连接完成。
